# TapiTranscriber

App Android che trascrive gli audio condivisi da WhatsApp, Telegram o da un'app di registrazione.
Tieni premuto un audio, tocca **Condividi** e scegli **TapiTranscriber**: la trascrizione compare in un popup con Copia, Condividi e Chiudi.

- Trascrizione con [Groq](https://console.groq.com/keys) (Whisper large v3 turbo), riserva [Gemini](https://aistudio.google.com/apikey). Entrambi hanno un piano gratuito; le chiavi le inserisce ognuno nell'app.
- L'audio non viene mai salvato: si legge in memoria, si invia e si libera.
- Le chiavi restano nelle impostazioni dell'app (e nel backup di Android), mai in file o nel codice.
- Aggiornamenti dall'app stessa, dalle [Releases](https://github.com/tapinilife/tapitranscriber/releases/latest).

## Installazione

Scarica l'APK dall'[ultima release](https://github.com/tapinilife/tapitranscriber/releases/latest) e aprilo sul telefono (Android 8 o successivo).
